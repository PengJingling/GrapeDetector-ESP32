# PCB expansion-board wiring summary

This file summarizes the provided PCB wiring document for the grape detection project.

## Current project priority

For the grape project, the minimum useful hardware is:

1. ESP32-S3 lower board
2. OV2640 camera
3. AS7341 spectrum sensor
4. Stable white LED light
5. PC server for YOLO and fusion scoring

The other modules are optional for display, voice, tray motion, or environmental monitoring.

## Lower board: ESP32-S3

### Power

| Signal | Connect to |
| --- | --- |
| +5V | 5V UPS/USB 5V output |
| GND | Power GND |
| +3V3 | Generated by ESP32 board LDO |

All modules must share GND.

### Lower-board expansion 8P

Use this if AS7341 is wired directly to ESP32 instead of STM32.

| Expansion pin | Signal |
| ---: | --- |
| 1 | 3V3 |
| 2 | GND |
| 3 | GPIO19 |
| 4 | GPIO41 |
| 5 | DEBUG_TX / GPIO43 |
| 6 | DEBUG_RX / GPIO44 |
| 7 | 5V |
| 8 | GND |

Recommended direct AS7341 wiring:

| AS7341 | ESP32 expansion |
| --- | --- |
| VIN/VCC | 3V3 |
| GND | GND |
| SDA | GPIO19 |
| SCL | GPIO41 |
| INT | Not connected |

Then set this in `src/config.h`:

```cpp
#define AS7341_DIRECT_TO_ESP32 1
```

## Board-to-board connection

The PCB document uses an ESP32 lower board and STM32 upper board.

If the 10P connector is not available, use DuPont wires:

| ESP32 lower board | STM32 upper board | Function |
| --- | --- | --- |
| +5V | 5V | Power |
| GND | GND | Common ground |
| GPIO17 / UART_TX | PA10 / RX | ESP32 to STM32 |
| GPIO18 / UART_RX | PA9 / TX | STM32 to ESP32 |

TX/RX must cross:

```text
ESP32 TX -> STM32 RX
ESP32 RX <- STM32 TX
```

If both boards are powered by their own USB cables, do not connect 5V between them. Connect only GND, TX, and RX.

## Upper board: STM32

These devices are on the STM32 upper board in the PCB document.

### AS7341 spectrum sensor, important

| AS7341 signal | STM32 |
| --- | --- |
| VIN/VCC | 3V3 |
| GND | GND |
| SCL | PB6 |
| SDA | PB7 |
| INT | Not connected |

If using this PCB path, STM32 must read AS7341 and send spectrum data to ESP32 through UART.

### DHT22 / AM2302, optional

Environmental temperature/humidity data. Helpful for a richer dashboard, not required for grape detection.

| DHT22 signal | STM32 |
| --- | --- |
| VCC | 3V3 |
| DATA | PA0 |
| GND | GND |

### ULN2003 stepper motor driver, optional

Useful if you want a rotating tray.

| ULN2003 signal | STM32 |
| --- | --- |
| IN1 | PB12 through 100R |
| IN2 | PB13 through 100R |
| IN3 | PB14 through 100R |
| IN4 | PB15 through 100R |
| VCC | 5V |
| GND | GND |

## Recommended first-stage build

Because the current goal is grape detection, build in this order:

1. ESP32 + OV2640 only: verify `/capture.jpg`.
2. Add AS7341 directly to ESP32 GPIO19/GPIO41 if you do not want STM32 yet.
3. Add white LED and fixed tray.
4. Add PC YOLO + fusion scoring.
5. Add ST7796 display, STM32 AS7341 path, DHT22, motor, or audio only after the core detection works.
